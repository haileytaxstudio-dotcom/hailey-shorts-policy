개인정보처리방침 – 쇼츠 예약

시행일: 2026년 11월 25일

'쇼츠 예약'(이하 "앱")은 세무사 헤일리가 본인이 운영하는 YouTube 채널 '세무사 헤일리의 합격노트'에 직접 제작한 쇼츠 영상을 예약 업로드하기 위해 만든 내부용 도구입니다. 앱의 사용자는 운영자 본인 1명이며, 외부 사용자에게 제공되지 않습니다.

1. YouTube API 서비스 이용

앱은 YouTube API 서비스를 이용합니다. 앱을 사용하는 것은 YouTube 서비스 약관에 동의하는 것이며, Google의 개인정보 처리는 Google 개인정보처리방침을 따릅니다.

2. 처리하는 정보

  • Google OAuth 인증 토큰: YouTube 채널에 영상을 업로드하고 재생목록에 추가하기 위해 사용합니다.
  • YouTube 채널 정보(채널 이름, 재생목록 목록): 업로드 대상 채널과 재생목록을 확인하는 데만 사용합니다.
  • 운영자의 Google Drive 폴더에 있는 영상 파일과 Google 시트의 제목·설명: 업로드할 내용으로만 사용합니다.

앱은 다른 YouTube 이용자의 정보나 시청자 데이터를 수집하지 않습니다.

3. 보관 및 보호

인증 토큰은 운영자 계정의 Google Apps Script 프로젝트 속성에만 저장되며, 외부 서버나 데이터베이스로 전송하지 않습니다. 업로드 기록(파일명, 예정일, 영상 링크)은 운영자의 Google 시트에만 저장됩니다.

4. 제3자 제공

앱은 어떤 정보도 제3자에게 판매·공유·제공하지 않습니다.

5. 권한 철회 및 삭제

언제든지 Google 계정 보안 설정에서 '쇼츠 예약' 앱의 접근 권한을 철회할 수 있습니다. 철회하면 앱은 더 이상 YouTube 채널에 접근할 수 없으며, 저장된 토큰은 Apps Script 프로젝트 속성에서 삭제됩니다.

Privacy Policy – Shorts Scheduler (쇼츠 예약)

Effective date: November 25, 2026

"쇼츠 예약" (the "App") is an internal tool built by Hailey, a licensed tax accountant, to schedule uploads of her own Shorts videos to her own YouTube channel, "세무사 헤일리의 합격노트". The only user of the App is the channel owner; it is not offered to anyone else.

1. Use of YouTube API Services

The App uses YouTube API Services. By using the App you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

2. Information the App accesses

  • Google OAuth tokens, used only to upload videos to the owner's channel and add them to a playlist.
  • Channel information (channel name, list of the channel's playlists), used only to confirm the upload target.
  • Video files in the owner's Google Drive folder and titles/descriptions in the owner's Google Sheet, used only as the content to upload.

The App does not collect information about other YouTube users or viewers.

3. Storage and security

OAuth tokens are stored only in the Script Properties of the owner's Google Apps Script project and are never sent to any external server or database. Upload records (file name, scheduled date, video link) are kept only in the owner's Google Sheet.

4. Sharing

The App does not sell, share, or disclose any information to third parties.

5. Revoking access and deletion

Access can be revoked at any time via the Google security settings page. After revocation the App can no longer access the channel, and stored tokens are deleted from the Script Properties.
